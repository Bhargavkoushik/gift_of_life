

# Gift of Life

Project scaffold for the blood donation application.

## Structure

- `backend/` - backend service code with `src/` modules, middleware, services, database, config, utils, routes, `app.js`, and `server.js`
- `frontend/` - frontend application code with role-based screens, shared components, layouts, services, hooks, context, routes, utils, assets, `App.jsx`, and `main.jsx`

## Notes

This repository currently contains a starter scaffold only. Install dependencies in each package before running the apps.
